# Conversor de Texto a Voz

Proyecto simple en Python que convierte texto ingresado por el usuario en un archivo de audio.  
Este proyecto forma parte de mi proceso de aprendizaje en programación y uso de librerías externas.

## 🚀 Tecnologías utilizadas
- Python
- Librería de síntesis de voz (por ejemplo: gTTS)

## 🧩 Funcionalidades
- Ingreso de texto por consola
- Conversión del texto a audio
- Generación de un archivo de sonido
- Manejo básico de funciones y archivos

## 🎯 Objetivo del proyecto
Practicar:
- Integración de librerías externas
- Manejo de archivos
- Flujo de datos
- Organización de código en Python

## 📂 Estructura del proyecto
- `texto_a_voz.py` → Script principal del programa

## 📌 Mejoras futuras
- Interfaz gráfica
- Selección de voces
- Ajuste de velocidad y tono
- Exportación en distintos formatos de audio
